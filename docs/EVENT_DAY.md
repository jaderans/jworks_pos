# Event day checklist

## The week before

- **Events → New event** (or copy a past one). Add the booth fee when you create it.
- **Event → Edit prices**: set this event's prices. Turn on *Booth-aware pricing* to see each product's floor price and a suggested price for your profit target. Base prices stay as they are.
- **Products → Bundle deals**: set up deals like *Cat Meme ×4 for ₱75*. They apply themselves at the register.
- **Production**: make sure what you're selling has a cost (by hand, recipe or batch). Log any production runs.
- **Event → Stock**: enter how many of each item you're bringing.
- **Event → Booth spend**: list everything: booth fee, tarps and cards (used up), stands (reusable, spread over events), materials. Mark what's bought and who paid.
- **Event → Team & payouts**: add who's on duty and their shifts.
- **Settings → Payment methods**: upload your GCash and Maribank QR images.
- Every phone that will sell: open the app once online, install it, and give it its own register letter (A, B, C…).

## On the day

1. Open the app (no internet needed) and pick the event at the top.
2. **Sell → Open register** with the float you counted.
3. Sell. For GCash or bank transfers, type the reference number from the customer's screen and check it arrived before handing over the items.
4. Money that isn't a sale (water, tricycle, extra coins): **Cash in/out**.
5. Mistakes: **Sales** → tap the sale → *Void* (with a reason) or *Change payment*. Cashiers need the owner PIN.

## Closing

1. **Close register**: count each denomination. The app shows expected vs counted, over or short, and the e-wallet totals to check against your apps.
2. Save the backup file it offers (share it to Drive or Messenger when online).
3. Second phone without cloud sync: on that phone **Settings → Backup and devices → Share this device's data**; on the main phone **Merge a file**. Merging the same file twice is safe.
4. **Event → Team & payouts → Save payouts**, then mark each one paid.
5. **Event → Report**: full PDF, one-page summary for the team chat, payout slips.
6. **Mark as reported** when everything is filed.
